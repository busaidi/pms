# Approved Atheer short-stay template, version 1

Approved source: the owner's selected stay-contract layout. The original signed document is private and is not part of this repository.

Pages 4–11 contain only the standard terms and their page numbers. They were
rendered to clean PNGs so obsolete, invisible PDF text layers (including unrelated
invoice text and previous contract references) cannot leak into generated copies.
Pages 1–3 and 12 are populated by `templates/properties/contracts/atheer_short_v1.html`.
No source tenant identity, signature image, or production database belongs here.

Keep these versioned assets unchanged once issued documents use them. New approved
wording/design needs a new template version and renderer support for old versions.
The missing article 9 is preserved from the approved source, not silently rewritten.
